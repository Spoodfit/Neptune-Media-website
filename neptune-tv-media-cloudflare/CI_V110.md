# Production CI v111

Cette version ne modifie aucune logique métier Neptune Media.

Invariants :
- le déploiement Cloudflare appelle un seul vérificateur canonique Studio/Catalogue : `verify-studio-information-architecture-production-v65.mjs` ;
- le workflow de déploiement ne duplique plus les assertions internes du Catalogue v109 ;
- les contrôles production v93, v94, éditorial, Resend et accès client restent séparés ;
- les anciens workflows auto-modifiants `build-client-portal.yml`, `implement-studio-password-reset.yml` et `upgrade-client-account.yml` sont supprimés ;
- les diagnostics `visual-render-audit.yml`, `diagnose-story-home-production.yml` et `diagnose-streaming-production.yml` sont en lecture seule et conservent leurs preuves via GitHub Artifacts au lieu de pousser des commits bot dans `main` ;
- `npm run check` exécute `verify-production-ci-v110.mjs` (contrat renforcé v111) afin d'empêcher le retour de ces incohérences.
