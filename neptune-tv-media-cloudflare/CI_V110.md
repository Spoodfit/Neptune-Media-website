# Production CI v113

Cette version finalise l’audit du Catalogue et de la chaîne de production sans modifier les données métier D1/R2.

Invariants :
- le déploiement Cloudflare appelle un seul vérificateur canonique Studio/Catalogue : `verify-studio-information-architecture-production-v65.mjs` ;
- le workflow de déploiement ne duplique plus les assertions internes du Catalogue v109 ;
- aucun workflow GitHub Actions n’a le droit d’écrire dans le dépôt ou de pousser un commit généré vers `main` ;
- les anciens builders, auto-patchers, hotfix deployers et audits versionnés devenus obsolètes sont supprimés ;
- les diagnostics utiles sont en lecture seule et conservent leurs preuves via GitHub Artifacts ;
- `validate-streaming-source.yml` valide le code courant sans exécuter le script qui le transforme ;
- `diagnose-client-portal-production.yml`, `diagnose-public-accessibility.yml` et `import-launch-emissions.yml` ne committent plus leurs rapports dans Git ;
- le diagnostic du catalogue public valide les données publiées plutôt que des détails HTTP non fonctionnels comme `HEAD`, ETag ou `no-store` ;
- le gate UI conserve les contrôles utiles (overflow, IDs, images cassées, cibles tactiles, lecteur vidéo, structure actuelle) et se déclenche uniquement après le déploiement Cloudflare canonique ;
- les anciennes URLs de posters HORS NORME sont normalisées vers l’asset maintenu ; l’ancienne URL Connexio utilise le poster neutre tant qu’aucun visuel source autoritatif n’est fourni ;
- le Store actif limite à trois demandes de réinitialisation du compte Studio sur une fenêtre de quinze minutes, avec réponse générique en cas de throttling ;
- `npm run check` exécute `verify-production-ci-v110.mjs`, dont le contrat est renforcé en v113 et inspecte tous les workflows du dépôt.
