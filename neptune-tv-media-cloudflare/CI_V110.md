# Production CI v112

Cette version finalise l’audit sans modifier la logique métier du Catalogue Neptune Media.

Invariants :
- le déploiement Cloudflare appelle un seul vérificateur canonique Studio/Catalogue : `verify-studio-information-architecture-production-v65.mjs` ;
- le workflow de déploiement ne duplique plus les assertions internes du Catalogue v109 ;
- les anciens builders/auto-patchers `build-client-portal.yml`, `implement-studio-password-reset.yml`, `upgrade-client-account.yml` et `post-deploy-render-polish.yml` sont supprimés ;
- les diagnostics AIDA/home historiques redondants sont supprimés au profit d’un seul diagnostic streaming stable ;
- `visual-render-audit.yml`, `diagnose-streaming-production.yml` et `ui-quality-gate.yml` sont en lecture seule et publient leurs preuves via GitHub Artifacts ;
- le diagnostic du catalogue public valide les données publiées plutôt que des détails HTTP non fonctionnels comme `HEAD`, ETag ou `no-store` ;
- le gate UI conserve les contrôles utiles (overflow, IDs, images cassées, cibles tactiles, lecteur vidéo, structure actuelle) et ne dépend plus d’anciens composants supprimés ;
- les anciennes URLs de posters HORS NORME sont normalisées vers l’asset maintenu ; l’ancienne URL Connexio utilise le poster neutre tant qu’aucun visuel source autoritatif n’est fourni ;
- `npm run check` exécute `verify-production-ci-v110.mjs`, dont le contrat est renforcé en v112.
