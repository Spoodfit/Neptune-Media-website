# Visuels Catalogue Media v98

Les visuels initiaux `hors-norme.svg` et `connexio.svg` proviennent des miniatures fournies pour finaliser le catalogue Neptune Media.

Après déploiement v98, les visuels de concepts et configurations sont administrables directement depuis Studio > Catalogue Media. Les nouveaux imports sont stockés dans R2 et deviennent la source de vérité du tunnel de réservation.
