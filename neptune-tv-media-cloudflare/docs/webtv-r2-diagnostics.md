# Web TV — diagnostic R2

Quand l’import direct R2 n’est pas considéré comme configuré, le Worker renvoie uniquement des indicateurs booléens de présence/validation pour `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_S3_ENDPOINT` et `R2_ACCOUNT_ID`.

Aucune valeur, aucun préfixe, aucune longueur et aucun fragment de secret ne doit être exposé au Studio.
